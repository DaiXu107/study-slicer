## 为什么是 Study Slicer

- **课题太大，不知道今天做什么？** 四步向导把「一个研究课题」拆成每天 20–45 分钟、有明确完成标准的小任务。
- **文献读不完、读完就忘？** 内置阅读工作台：摘要、解读、笔记、粘贴全文、划词翻译 / 搜索 / 拓展文献。
- **引用格式调到崩溃？** 七种格式一键生成，只导出真正用到的核心文献，复制或下载都行。
- **不想让 AI 替你思考？** 严格模式下第 3 步零 AI 请求，AI 只负责规划任务；甚至可以全程用阶段模板，零 AI。
- **不想注册、不想上传数据？** 纯前端、无后端、无账号、无埋点。

## 核心优势

- **从课题到今日行动**：课题 → 文献 → 方向 → 每日任务，四步闭环，每一步都能回退修改。
- **真正的“小步”**：每个任务 20–45 分钟，必须写清「完成标准」，不是“今天读文献”这种空话。
- **文献到引用的闭环**：OpenAlex 检索 + 本地 BibTeX / RIS 导入 → 阅读器精读 → 勾选核心文献 → APA / GB-T / BibTeX 等一键导出。
- **AI 可关、可限、可审计**：完整辅助 / 仅任务规划（严格）/ 阶段模板三条路径，课题会记录创建时的 AI 模式。
- **失败也有退路**：OpenAlex 挂了可手动录入；LLM 失败可复制提示词；无 Key 可用六套阶段模板。
- **本地优先**：所有数据只存 localStorage，刷新不丢；关闭页面前还会强制落盘一次。
- **可换肤、可扩展**：内置四套主题，支持导入声明式主题包；语言包格式已预留。
- **为手机打卡设计**：大字号、留白、底部导航、单手可完成；桌面端同样舒适。
- **开箱即用**：不需要数据库、不需要服务端；`npm install && npm run dev` 就能跑。

## 使用流程

1. **写下课题**：标题 + 当前阶段 +（可选）英文关键词。
2. **挑几篇文献**：OpenAlex 按被引数给出 10 篇，勾选你真正想读的 3–5 篇；搜不到就手动录。
3. **形成方向**：完整辅助模式让 AI 生成解读与 3 个方向；严格模式完全由你写。
4. **拆成每天一小块**：AI 或阶段模板生成任务，逐条改到可执行。
5. **每天打卡**：完成、写笔记、看 streak 和本周完成率。
6. **收尾导出**：在文献库勾选核心文献，导出引用列表，贴进论文。

## 四步向导

1. **设定课题**：课题标题、研究阶段、可选关键词。阶段只影响任务模板，之后可改。
2. **文献检索**：OpenAlex 免 Key，按被引数取 10 篇；勾选 3–5 篇。接口失败时用手动录入，流程不中断。重新搜索会保留手动录入的文献。
3. **解读与方向**：完整辅助模式生成每篇的三句话解读 + 3 个可切入方向；严格模式完全手动。没配 API Key 时可以复制提示词去 ChatGPT / Claude 跑。方向标题、描述、可行性都能改。
4. **拆解每日任务**：AI 生成 10–15 个任务，或按六套阶段模板本地生成 12 个。每个任务都有完成标准和预计时长；标题、描述、标准、日期都可编辑或删除。

向导草稿保存在 `study-slicer:draft:v1`，刷新、关标签页、暂时离开都不会丢。

## 添加本地文献

文献库顶部的「添加文献」支持两种方式：

- **手动录入**：标题、作者、年份、期刊 / 来源、DOI、摘要、原文链接，归入指定课题。
- **导入文件**：支持 `.bib`（BibTeX）、`.ris`（RIS）和 `.txt`，单文件最大 1 MB。
  - 先解析并展示预览，勾选要导入的条目。
  - 自动按 DOI / 标题去重，已在当前课题里的文献会标记「已在库中」并禁止重复导入。
  - 多个课题时可选择导入目标。

导入的文献和 OpenAlex 检索来的文献一视同仁：阅读器、笔记、划词、引用导出都能用。

> PDF 暂不直接解析。你可以先把 PDF 正文复制到阅读器的「全文」里；PDF 上传解析在路线图中。

## 文献阅读器

在文献库点任意文献的「阅读」，进入全屏阅读工作台：

- **摘要**：大字号、宽行距，适合手机精读。
- **三句话解读**：AI 或你手动写的内容。
- **我的笔记**：自动保存到本机。
- **粘贴全文**：把 PDF / 网页正文复制进来，在站内继续读；上限 10 万字符，只存本机，不上传。
- **划词工具**：选中摘要或全文里的词句，底部弹出：
  - **AI 速译**：使用你配置的模型，结合课题与摘要语境翻译并解释（完整辅助模式；严格模式不显示）。
  - **搜索词义**：Bing。
  - **学术搜索**：Semantic Scholar。
  - **OpenAlex 找文献**：相关性检索，结果可直接加入当前课题文献库。
- **原文**：一键在新标签页打开。

### 为什么不是内置浏览器？

出版社页面普遍设置 `X-Frame-Options` / CSP，禁止被其他网站嵌入。纯前端应用无法绕过，也不应该做一个经常白屏的 iframe。所以：

- 原文统一在新标签页打开；
- 站内提供摘要、可粘贴全文、解读、笔记和划词工具；
- 这样既能安静阅读，也不依赖不稳定的页面嵌入。

## 参考文献导出

在文献库右上角点「导出引用」：

- 默认勾选每个课题中标记为**核心**的文献；如果都没有核心标记，默认全选。
- 可以手动勾选、全选、清空。
- 支持 **APA 7 / MLA 9 / Chicago / GB/T 7714 / IEEE / BibTeX / RIS**。
- 实时预览，复制到剪贴板，或下载 `.txt` / `.bib` / `.ris`。
- OpenAlex 会补充期刊、卷、期、页码、DOI；手动录入也可以填写期刊与 DOI。
- BibTeX 与 RIS 可直接导入 Zotero、EndNote 等文献管理器。

**注意**：作者姓名拆分、缩写、标点是启发式处理，投稿前请按目标期刊或学校要求核对一遍。没有期刊信息的条目会降级为网页 / 一般条目格式。

## 三种 AI 参与方式

**完整辅助**

- 第 3 步：AI 生成每篇的三句话解读与 3 个研究方向，可逐条修改。
- 第 4 步：AI 拆解任务，也可以改用阶段模板。
- 适合：想快速起步、愿意在 AI 草稿上改的人。

**仅任务规划 · 严格**

- 第 3 步：你写解读与方向，AI 不参与，零请求。
- 第 4 步：AI 只拆你写好的方向，也可以改用阶段模板。
- 适合：研究判断必须自己做、只需要 AI 帮忙排期的人。

**全程零 AI**

- 第 3 步：你写。
- 第 4 步：使用阶段模板。
- 适合：完全不想调用任何模型的人。

严格模式的具体保证：

- 第 3 步没有生成按钮、不调用接口、也不生成可复制提示词。
- 第 4 步只发送课题标题、阶段，以及**你写好的**方向标题与描述；不发送文献摘要、解读或研究结论。
- 任务生成 prompt 明确禁止 AI 新增研究方向或研究判断。
- 阅读器里的划词 AI 翻译也会禁用。
- 课题会记录创建时的模式，项目卡片和主页显示「AI 仅规划」。
- 切换模式不会自动删除草稿里已有内容；想从零开始，用第 1 步的「清空草稿，重新开始」。

## 外观与扩展

设置 → **外观与扩展**：

- 内置四套主题：**纸感 / 午夜 / 海盐 / 森野**，一键切换。
- **导入主题包**：只接受声明式 JSON，15 个 `#RRGGBB` 颜色 token；格式不对整包拒绝。
- 主题只改颜色，不执行 JavaScript、不注入任意 CSS、不联网。
- 主题只保存在本机，可随时删除；删除当前主题会自动回到「纸感」。
- 提供「下载主题模板」，并附带一个可直接导入的示例：`plugins/themes/sakura-mist.json`。
- 格式文档：`docs/PLUGINS.md`。

**语言包**：格式、模板和入口已经预留。完整语言切换需要把全部界面文案抽成 key，计划在下一阶段启用；现在可以先按模板准备翻译，届时同一份 JSON 直接导入即可。语言包同样只接受键值对，不允许 HTML 或脚本。

## 降级与容错

- **OpenAlex 连不上 / 返回错误**：显示提示，自动展开手动录入表单，流程继续。
- **搜索没有结果**：提示换更宽泛的英文关键词，或手动录入。
- **没有配置 API Key**：第 3 步给可复制提示词；第 4 步用阶段模板。
- **LLM 调用失败 / 超时 / CORS**：回退到复制提示词模式，任务可改用阶段模板。
- **AI 返回的 JSON 不完整**：容错解析，失败时提示重试，不破坏已有内容。
- **浏览器关闭 / 刷新**：防抖保存 + `pagehide` / `beforeunload` 强制落盘。
- **今天没有任务**：显示「休息或补昨天」并列出可补项。

## 数据与隐私

- `study-slicer:v1`：项目、任务、文献、方向、设置（含 API Key）、粘贴的全文。
- `study-slicer:draft:v1`：未完成的向导草稿。
- 没有服务器、没有账号、没有埋点。
- 只有在你点击「生成解读 / 拆解任务 / AI 速译」时，相关文本才会发送到你填写的模型接口。
- 粘贴的全文、笔记、任务始终只在本机。
- 清理浏览器数据或换设备会丢失内容；重要笔记请自行备份。
- API Key 存在浏览器本地，不要在共享设备上填写。

## 关于 OpenAlex

- 无需注册或 API Key。
- 向导中的检索按需求使用 `sort=cited_by_count:desc`，更偏「领域内高被引」。
- 阅读器里的「找文献」改为相关性排序，更适合拓展阅读。
- OpenAlex 对英文关键词更敏感；中文课题建议先用英文关键词检索一次。
- 部分文献没有公开摘要，可以手动补录或直接读原文。

## 技术栈

- **React 18** + **TypeScript 5**
- **Tailwind CSS 3**：深蓝主色、暖橙强调、低饱和完成绿
- **Vite 5**：开发与构建
- **React Router 6**：HashRouter，静态部署友好
- **localStorage**：无后端持久化
- **OpenAlex API**：免 Key 文献检索
- **OpenAI 兼容接口**：解读、方向、任务拆解、划词翻译

### 一些工程细节

- OpenAlex 的 `abstract_inverted_index` 在前端还原为可读摘要。
- 引用引擎独立在 `src/lib/citations.ts`，支持七种格式、BibTeX key 去重、RIS 页码拆分。
- 严格模式在 UI 和函数层双重加闸，避免任何遗漏的 AI 请求。
- 阅读器和导出弹窗使用 Portal 挂到 `body`，避免被页面入场动画的层叠上下文裁切。
- 课题/草稿双 localStorage 命名空间；保存防抖 + 关闭前强制落盘。
- 全文粘贴上限 10 万字符，避免 localStorage 无限膨胀。

## 配置 AI（可选）

在「设置」里填任意 **OpenAI 兼容**的 Chat Completions 接口：

- Base URL 填到 `/v1` 即可，例如 `https://api.openai.com/v1`；误填完整 `/chat/completions` 地址也会自动处理。
- API Key 只保存在本机 localStorage，只会发送给你填写的接口地址。
- 默认模型：`gpt-4o-mini`。
- 可填任意兼容服务或自建代理。

**跨域提示**：浏览器会直接请求该接口。部分服务商不允许浏览器跨域访问（CORS），「测试连接」会失败；请换用允许浏览器访问的接口或代理。没有 Key 也不影响使用。

## 已知限制

- 数据只在本机，暂不支持云同步；引用可以导出，课题数据本身暂未提供备份。
- 浏览器直连 LLM 可能受 CORS 限制。
- AI 输出质量取决于所选模型；所有生成内容都设计成可手动修改。
- OpenAlex 的按被引排序可能带出领域外的经典文献，可通过更精确的关键词重搜或手动录入；阅读器相关文献已改用相关性排序。
- 出版社网页通常禁止 iframe 嵌入，站内阅读器提供摘要 / 粘贴全文 / 解读 / 笔记，不提供任意原文页面内嵌。
- 引用格式由元数据自动生成，作者姓名拆分、缩写和标点是启发式的；投稿前请人工核对。
- 划词 AI 翻译会使用设置里的模型；严格模式下该功能禁用，只保留外部搜索与 OpenAlex 检索。
- 粘贴全文最多 10 万字符，且只存当前浏览器。
- 文献库暂不支持直接解析 PDF；支持手动录入与 BibTeX / RIS 导入。
- 语言切换尚未启用；语言包格式与入口已预留。
- 主题只覆盖 15 个颜色 token，暂不支持布局、字体、圆角或背景纹理。
- 自定义主题只存在当前浏览器；换设备需要重新导入 JSON。
