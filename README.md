# Study Slicer · 课题切片

把 PhD / 硕士课题切成「今天 45 分钟内能做完的一小块」。

纯前端单页应用：React + TypeScript + Tailwind CSS + Vite。没有账号、没有后端，所有课题、任务、笔记和设置都存在浏览器的 localStorage 里。

## 在线使用

👉 **https://daixu107.github.io/study-slicer/**

无需安装、无需登录。数据只存在你自己的浏览器里。

## 快速开始

```bash
npm install
npm run dev
```

打开终端里提示的地址（默认 `http://localhost:5173`）。

其他命令：

```bash
npm run typecheck   # TypeScript 类型检查
npm run build       # 类型检查 + 生产构建，产物在 dist/
npm run preview     # 本地预览生产构建
```

## 功能

### 四步课题向导

1. **设定课题**：课题标题、当前阶段（文献综述 / 理论框架 / 方法论设计 / 数据收集 / 分析 / 写作）、可选关键词。
2. **文献检索**：调用 OpenAlex（无需 Key），按被引数从高到低取 10 篇，展示标题、作者、年份、摘要前 200 字、被引数和原文链接。勾选 3–5 篇；接口失败时可直接手动录入文献。
3. **解读与方向**：完整辅助模式下调用 OpenAI 兼容接口，为每篇文献生成三句话解读，并给出 3 个可切入方向（含两句描述与可行性）。没配 API Key 时自动进入「可复制提示词」模式，并展示摘要，方便贴到 ChatGPT / Claude 里跑。选择「仅任务规划」严格模式时，这一步不调用 AI，完全由你手动完成。方向可手动增删改。
4. **拆解每日任务**：让 AI 生成 10–15 个 20–45 分钟的任务，或按阶段模板本地生成 12 个。任务标题、描述、完成标准、日期、预计时长都可编辑或删除。

向导草稿会自动保存在 localStorage，刷新或暂时离开不会丢；每一步都能返回修改。

### 每日打卡

- 今日任务、连续打卡天数、本周完成率
- 勾选完成、记录完成时间、轻量 confetti 动画
- 每个任务可写一句笔记
- 完成后展示「明日预告」
- 今天没任务时，列出可以补做的过期任务

### 项目 / 文献库 / 设置

- **项目**：进度条、阶段标签、进入与删除
- **文献库**：所有已拉取文献、核心文献标记、AI 三句话解读、可编辑笔记、阅读器、引用导出
- **设置**：AI 参与范围、API Base URL、API Key、模型名、测试连接

## 文献阅读器

在文献库点任意文献的「阅读」，进入全屏阅读工作台：大字号摘要、三句话解读、可编辑笔记。

**读全文**：可以点「粘贴全文」，把 PDF 或网页正文复制进来，在站内以大字号阅读；全文只保存在本机 localStorage（上限 10 万字符），不会上传。划词工具对摘要和粘贴的全文都生效。

选中文字后，底部会出现划词工具：

- **AI 速译**：使用你在设置里配置的模型，结合摘要语境翻译并解释（完整辅助模式；严格模式不显示，也不会发起请求）。
- **搜索词义**：打开 Bing 搜索。
- **学术搜索**：打开 Semantic Scholar 搜索。
- **OpenAlex 找文献**：按**相关性**检索（不是按被引数），结果可直接加入当前课题的文献库。

**关于“像浏览器一样阅读原文”**：出版社页面普遍设置 `X-Frame-Options` / CSP，禁止被其他网站嵌入；纯前端应用无法绕过，也不应该伪造一个经常白屏的 iframe。因此原文统一在新标签页打开；站内提供摘要、可粘贴全文、解读、笔记和划词工具。OpenAlex 未收录摘要时会提示去原文阅读。

## 引用导出

文献库右上角「导出引用」：

- 默认勾选每个课题中标记为**核心**的文献；如果都没有核心标记，则默认全选。可手动勾选、全选或清空。
- 支持 **APA 7 / MLA 9 / Chicago / GB/T 7714 / IEEE / BibTeX / RIS**。
- 支持预览、复制，以及下载 `.txt` / `.bib` / `.ris`。
- OpenAlex 会自动补充期刊、卷、期、页码、DOI；手动录入文献时也可以填期刊和 DOI。
- 引用列表由元数据自动生成，作者缩写与标点是启发式处理。投稿前请按目标期刊或学校要求核对一遍。

**说明**：DOI 会输出为 `https://doi.org/...`；没有期刊信息的条目会降级为网页/一般条目格式。BibTeX 与 RIS 可直接导入 Zotero、EndNote 等文献管理器。

## 配置 AI（可选）

在「设置」里填任意 **OpenAI 兼容**的 Chat Completions 接口：

- Base URL 填到 `/v1` 即可，例如 `https://api.openai.com/v1`；如果误填了完整 `/chat/completions` 地址也会自动处理。
- API Key 只保存在本机 localStorage，只会发送给你填写的接口地址。
- 默认模型：`gpt-4o-mini`。

**跨域提示**：浏览器会直接请求该接口。部分服务商不允许浏览器跨域访问（CORS），此时「测试连接」会失败；请换用允许浏览器访问的接口或自建代理。没有 Key 也不影响使用：AI 步骤会降级为「复制提示词」，任务步骤会降级为「阶段模板」。

## AI 参与范围（严格模式）

如果希望研究内容完全由自己完成，只让 AI 协助规划时间，可以选择「仅任务规划」：

- 在「设置 → AI 参与范围」里设为默认值，或在向导第 1 步单独选择。
- **严格模式下，第 3 步完全不调用 AI**：没有生成按钮，不请求接口，也不生成可复制提示词；文献解读和研究方向全部由你撰写。
- 第 4 步只发送课题标题、阶段，以及**你写好的**方向标题与描述；不会发送文献摘要、解读或研究结论。任务生成指令里也明确禁止 AI 新增方向或研究判断。
- 第 4 步仍可选择「完全不调用 AI：用阶段模板」，此时整个流程零 AI 请求。
- 课题会记录创建时的模式，并在项目卡片和主页显示「AI 仅规划」。
- 切换模式不会自动删除草稿里已有的解读或方向；如果之前用 AI 生成过内容、想彻底从零开始，请用第 1 步的「清空草稿，重新开始」。
- 文献检索来自 OpenAlex 文献索引，不属于生成式 AI。

## 数据与隐私

| localStorage key | 内容 |
| --- | --- |
| `study-slicer:v1` | 项目、任务、文献、方向、设置（含 API Key） |
| `study-slicer:draft:v1` | 未完成的向导草稿 |

- 没有服务器，没有埋点，没有登录。
- 清理浏览器数据 / 换设备会丢失内容，重要笔记请自行备份。
- API Key 存在浏览器本地，不要在共享设备上填写。

## 关于 OpenAlex

- 无需注册或 API Key。
- 检索请求按需求使用 `sort=cited_by_count:desc`，因此结果更偏「领域内高被引」而不是「与你最相关」。
- OpenAlex 对英文关键词更敏感；中文课题建议先用英文关键词检索一次。
- 部分文献没有公开摘要，可以手动补录。

## 已知限制

- 数据只在本机，暂不支持云同步；引用可以导出，课题数据本身暂未提供备份。
- 浏览器直连 LLM 可能受 CORS 限制。
- AI 输出质量取决于所选模型；所有生成内容都设计成可手动修改。
- OpenAlex 的按被引排序可能带出领域外的经典文献，可通过更精确的关键词重搜或手动录入；阅读器里的相关文献检索已改用相关性排序。
- 出版社网页通常禁止 iframe 嵌入，站内阅读器提供摘要/粘贴全文/解读/笔记，不提供任意原文页面内嵌。
- 引用格式由元数据自动生成，作者姓名拆分、缩写和标点是启发式的；投稿前请人工核对。
- 划词 AI 翻译会使用设置里的模型；严格模式下该功能禁用，只保留外部搜索与 OpenAlex 检索。
